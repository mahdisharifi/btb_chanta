# سرویس ویرایش عکس محصول

این ابزار آزمایشی مستقل فقط مدل تأییدشدهٔ `muse-image-1.0` را از درگاه AvalAI اجرا می‌کند. کاربر یک تصویر مرجع می‌فرستد؛ دستور ویرایش محصول در سرور ثابت است و در رابط قابل تغییر نیست. هیچ مدل یا درگاه دیگری در این سرویس فعال نیست.

## اجرا

1. `.env.example` را به `.env` کپی کنید و کلید AvalAI را در `AVALAI_AI_API_KEY` بگذارید.
2. در صورت نیاز نرخ تبدیل اعتبار به تومان را در `AVALAI_CREDIT_TOMAN` تنظیم کنید.
3. از همین پوشه اجرا کنید:

```bash
php -S 127.0.0.1:8791 -t public router.php
```

سپس صفحهٔ تست را در [http://127.0.0.1:8791](http://127.0.0.1:8791) باز کنید. همچنین می‌توانید آدرس API، کلید و نرخ تبدیل را از پنل تنظیمات خود صفحه ذخیره کنید. کلید فقط روی سرور می‌ماند.

## ویرایش و هزینه

تصویر مرجع به مسیر `/v1/images/edits` با شناسهٔ ثابت `muse-image-1.0` فرستاده می‌شود. پاسخ بدون تصویر خروجی به‌عنوان ویرایش موفق پذیرفته نمی‌شود. تصویر خروجی در رابط به مربع ۱۲۰۰×۱۲۰۰ آماده می‌شود.

تعرفهٔ درج‌شده برای Muse در حساب AvalAI برابر ۰٫۰۱ اعتبار پایه به‌اضافهٔ ۱۵٪ کارمزد است؛ یعنی برآورد ۰٫۰۱۱۵ اعتبار برای هر تصویر. اگر شناسهٔ درخواست و هزینهٔ تراکنش در User API در دسترس باشد، هزینهٔ ثبت‌شدهٔ واقعی نمایش داده می‌شود. نرخ تومان از تنظیمات قابل تغییر است.

دستور ثابت ویرایش در `src/ProductImagePrompt.php` نگهداری می‌شود.

## اتصال فرم محصول پلتفرم

فرم ایجاد محصول ادمین و تأمین‌کننده از `App\Services\MuseProductImageEditor` استفاده می‌کند. نخستین تصویر انتخاب‌شده به Muse فرستاده و خروجی ۱۲۰۰×۱۲۰۰ آن به‌عنوان فایل موقت تصویر اصلی فرم جایگزین می‌شود؛ تصاویر بعدی، ویدئو و تصویر بندانگشتی ویدئو از مسیر عادی پلتفرم عبور می‌کنند. تنظیمات پیش‌فرض این اتصال از همین `.env` خوانده می‌شود و در صورت نیاز متغیرهای `PRODUCT_IMAGE_AI_*` در `.env` اصلی پلتفرم می‌توانند آن را override کنند.
