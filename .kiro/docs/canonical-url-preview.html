🔍 پیش‌نمایش Canonical URL

نمونه محصول: ZQS-8315 | بهبودهای SEO اعمال شده

🌐 URLهای مختلف صفحه محصول

🟢 Canonical URL (همیشه ثابت)
https://example.com/products/zqs-8315-sample-product
URL فعلی کاربر (ممکن است پارامتر داشته باشد)
https://example.com/products/zqs-8315-sample-product?supplier_id=123&ref=homepage
URL دیگر (از لینک خارجی)
https://example.com/products/zqs-8315-sample-product?utm_source=google&utm_medium=cpc
✅
تمام URLهای بالا به یک Canonical اشاره می‌کنند

Google می‌داند که همه این URLها یک صفحه هستند و duplicate content ایجاد نمی‌کنند.

⚖️ مقایسه: قبل و بعد از بهبود

❌ روش قبلی (اشتباه)
// استفاده از url()->current() 'canonical_url' => url()->current() // خروجی: "https://example.com/products/zqs-8315?supplier_id=123" ⚠️ مشکل: هر بار URL متفاوت!
✅ روش جدید (صحیح)
// استفاده از route() 'canonical_url' => route('products.show', ['product' => $product->slug]) // خروجی: "https://example.com/products/zqs-8315-sample-product" ✅ همیشه ثابت و بدون پارامتر!

💻 کد پیاده‌سازی شده در ProductController

/** * SEO برای صفحه محصول با Canonical URL صحیح */ private function buildSeoData(Product $product, array $breadcrumbs): array { // ... // ✅ Canonical URL: همیشه به URL بدون پارامتر اشاره می‌کند // این کار از duplicate content جلوگیری می‌کند $canonicalUrl = $product->seo_canonical_url ?? route('products.show', ['product' => $product->slug]); return [ 'canonical_url' => $canonicalUrl, 'og_url' => $canonicalUrl, // ... ]; }

🎯 مزایای استفاده از Canonical URL صحیح

🚫
جلوگیری از Duplicate Content
Google می‌داند کدام URL اصلی است و duplicate content ایجاد نمی‌شود
📈
بهبود رتبه‌بندی SEO
تمام اعتبار و لینک‌های خارجی به یک URL متمرکز می‌شوند
🔗
یکپارچگی URL
در نتایج جستجوی Google همیشه یک URL نمایش داده می‌شود
⚡
Indexing سریع‌تر
Google bot زمان کمتری برای index کردن صفحات صرف می‌کند
💰
Page Authority بالاتر
اعتبار صفحه (PA) تقسیم نمی‌شود و روی یک URL متمرکز می‌شود
🎨
Rich Snippets بهتر
Schema.org markup راحت‌تر پردازش می‌شود و نتایج غنی‌تر نمایش داده می‌شوند

🧪 چگونه Canonical URL را تست کنیم؟

💡
راه‌های تست
  1. View Page Source: کلید راست → View Page Source → جستجوی "canonical"
  2. Google Search Console: URL Inspection Tool
  3. Browser DevTools: Elements tab → جستجوی "link[rel='canonical']"
  4. Online Tools: screaming frog, ahrefs site audit
# بررسی Canonical با CURL curl https://example.com/products/zqs-8315-sample-product | grep canonical # انتظار خروجی: <link rel="canonical" href="https://example.com/products/zqs-8315-sample-product">
