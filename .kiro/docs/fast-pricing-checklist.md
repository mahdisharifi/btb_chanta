## ✅ موارد اصلاح شده

### ۱. محاسبه قیمت چکی در `commitChanges()`
**مشکل:** قیمت چکی با درصد تیراژ محاسبه می‌شد (نادرست)

**اصلاح:** قیمت چکی = قیمت نقدی همان تیراژ × (1 + درصد دوره چک)

```php
// ✅ دریافت درصد اختصاصی این دوره چک از pivot
$checkPercentage = 0;
if ($checkPeriod->suppliers->isNotEmpty()) {
    $pivotData = $checkPeriod->suppliers->first()->pivot;
    $checkPercentage = $pivotData->percentage_increase ?? 0;
}

// ✅ فرمول صحیح
$calculatedPrice = $cashPrice * (1 + $checkPercentage / 100);
```

### ۲. منطق قفل‌گذاری سلول‌ها در Excel
**قانون:** هر کالا با توجه به تنظیمات خودش (`auto_calculate_tiers`)

| تنظیمات | قیمت نقدی مرجع | قیمت نقدی سایر تیراژها | قیمت چکی |
|---------|---------------|----------------------|----------|
| `auto_calculate = true` | ✅ قابل ویرایش | 🔒 قفل (فرمول‌دار) | 🔒 قفل (فرمول‌دار) |
| `auto_calculate = false` | ✅ قابل ویرایش | ✅ قابل ویرایش | ✅ قابل ویرایش |

## 🧪 سناریوهای تست

### تست ۱: کالا با `auto_calculate_tiers = true`

**پیش‌نیاز:**
- محصول با چند تیراژ
- `auto_calculate_tiers = true`
- تیراژ مرجع تعیین شده (`is_reference = true`)
- دوره‌های چکی فعال شده

**مراحل تست:**
1. دانلود Excel از `/supplier/fast-pricing/import`
2. بررسی سلول‌ها:
   - ✅ قیمت نقدی تیراژ مرجع: قابل ویرایش (سفید)
   - 🔒 قیمت نقدی سایر تیراژها: قفل (آبی روشن) با فرمول
   - 🔒 قیمت چکی همه تیراژها: قفل (آبی روشن) با فرمول
3. ویرایش فقط قیمت مرجع
4. آپلود فایل
5. بررسی در صفحه Review
6. تایید و بررسی قیمت‌های ذخیره شده

**نتیجه مورد انتظار:**
- قیمت نقدی تیراژهای دیگر = قیمت مرجع × (1 + درصد تیراژ)
- قیمت چکی = قیمت نقدی همان تیراژ × (1 + درصد دوره چک)

### تست ۲: کالا با `auto_calculate_tiers = false`

**پیش‌نیاز:**
- محصول با چند تیراژ
- `auto_calculate_tiers = false`

**مراحل تست:**
1. دانلود Excel
2. بررسی سلول‌ها:
   - ✅ همه قیمت‌ها قابل ویرایش (سفید)
   - هیچ فرمولی نیست
3. ویرایش همه قیمت‌ها
4. آپلود و تایید

**نتیجه مورد انتظار:**
- همه قیمت‌ها دقیقاً همان مقدار وارد شده ذخیره می‌شوند

### تست ۳: دوره‌های چکی فعال/غیرفعال

**پیش‌نیاز:**
- چند دوره چکی تعریف شده
- برخی فعال، برخی غیرفعال برای supplier

**مراحل تست:**
1. بررسی ستون‌های Excel
2. فقط دوره‌های فعال باید ستون داشته باشند

**نتیجه مورد انتظار:**
- ✅ فقط دوره‌های `supplier_check_period.is_active = true` در Excel

### تست ۴: تیراژهای فعال/غیرفعال

**پیش‌نیاز:**
- محصول با چند تیراژ
- برخی تیراژها در `tier_enabled` غیرفعال

**مراحل تست:**
1. بررسی سطرهای Excel
2. فقط تیراژهای فعال باید ستون داشته باشند

**نتیجه مورد انتظار:**
- ✅ فقط تیراژهای `tier_enabled[tier] = true` در Excel

## 📊 فرمت‌ها

### متادیتای ستون‌ها
```
T{tier_index}|PT{price_type_id}|CP{check_period_id}
```

مثال‌ها:
- `T0|PT1|CP0` = تیراژ 0، نقدی، بدون دوره چک
- `T1|PT2|CP3` = تیراژ 1، چکی، دوره چک 3

### فرمول‌های Excel

**نقدی غیر-مرجع:**
```
=RefCol*(1+tier_percentage/100)
```
با rounding:

```excel
=ROUND(RefCol*(1+tier_percentage/100), 0)      // nearest_1
=ROUND(RefCol*(1+tier_percentage/100)/5, 0)*5  // nearest_5
=ROUND(RefCol*(1+tier_percentage/100)/10, 0)*10 // nearest_10
...
```

**چکی:**
```
=CashCol*(1+check_percentage/100)
```
با rounding مشابه

## ⚠️ نکات مهم

1. **تغییر درصد دوره چک:** اگر درصد دوره چک در تنظیمات supplier تغییر کند، قیمت‌های چکی قبلی در آپلود بعدی به‌روز می‌شوند

2. **تغییر تیراژ مرجع:** اگر تیراژ مرجع تغییر کند، فرمول‌ها در آپلود بعدی به‌روز می‌شوند

3. **غیرفعال کردن تیراژ:** اگر تیراژی غیرفعال شود، ستون مربوطه در Excel بعدی نخواهد بود

4. **غیرفعال کردن دوره چک:** اگر دوره چکی غیرفعال شود، ستون مربوطه در Excel بعدی نخواهد بود
