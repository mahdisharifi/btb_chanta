# 📊 پیشنهاد: سیستم رُند کردن قیمت بر اساس رنج‌های قیمتی

**تاریخ:** 2026-09-05  
**وضعیت:** 🔍 در حال بررسی (منتظر تایید)

---

## 🎯 هدف

تأمین‌کننده بتواند برای **رنج‌های قیمتی مختلف**، نوع رُند کردن متفاوتی تعیین کند.

**مثال:**
- قیمت‌های زیر 100,000 تومان → رُند هر 500 به بالا
- قیمت‌های 100,000 تا 500,000 → رُند هر 1,000 به بالا
- قیمت‌های بالای 500,000 → رُند هر 5,000 به بالا

---

## 🏗️ ساختار Database

### جدول جدید: `supplier_price_rounding_ranges`

```sql
CREATE TABLE supplier_price_rounding_ranges (
    id BIGINT UNSIGNED AUTO_INCREMENT PRIMARY KEY,
    supplier_id BIGINT UNSIGNED NOT NULL,
    
    -- رنج قیمتی
    min_price DECIMAL(15,2) NOT NULL DEFAULT 0,
    max_price DECIMAL(15,2) NULL, -- NULL = بدون محدودیت بالا
    
    -- تنظیمات رُند
    rounding_method ENUM('ceil', 'floor', 'nearest') NOT NULL DEFAULT 'ceil',
    rounding_step INT UNSIGNED NOT NULL DEFAULT 100, -- 100, 500, 1000, 5000, etc.
    
    -- اولویت (برای ترتیب اعمال)
    priority INT NOT NULL DEFAULT 0,
    
    -- فعال/غیرفعال
    is_active BOOLEAN DEFAULT TRUE,
    
    created_at TIMESTAMP NULL,
    updated_at TIMESTAMP NULL,
    
    FOREIGN KEY (supplier_id) REFERENCES suppliers(id) ON DELETE CASCADE,
    
    -- هر تأمین‌کننده نمی‌تواند رنج‌های همپوشانی داشته باشد
    INDEX idx_supplier_price (supplier_id, min_price, max_price)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci;
```

## 🔧 انواع Rounding

### 1. **ceil** (رُند به بالا)
```php
// قیمت: 49,600 | مبلغ مرجع: 500
ceil(49600 / 500) * 500 = 50,000 ✅
```

### 2. **floor** (رُند به پایین)
```php
// قیمت: 49,600 | مبلغ مرجع: 500
floor(49600 / 500) * 500 = 49,500 ✅
```

### 3. **nearest** (نزدیک‌ترین)
```php
// قیمت: 49,600 | مبلغ مرجع: 500
round(49600 / 500) * 500 = 50,000 ✅

// قیمت: 49,200 | مبلغ مرجع: 500
round(49200 / 500) * 500 = 49,000 ✅
```

## 📝 مثال کامل

### تنظیمات:
```
رنج 1: 0 - 100,000 | ceil | 500
رنج 2: 100,000 - 500,000 | ceil | 1,000
رنج 3: 500,000+ | ceil | 5,000
```

### نمونه قیمت‌ها:
```
قیمت 49,600:
  → رنج 1 (0-100k)
  → ceil | 500
  → ceil(49600/500) * 500 = 50,000 ✅

  → رنج 1 (0-100k)
  → ceil | 500
  → ceil(35100/500) * 500 = 35,500 ✅

قیمت 150,200:
  → رنج 2 (100k-500k)
  → ceil | 1,000
  → ceil(150200/1000) * 1000 = 151,000 ✅

قیمت 756,200:
  → رنج 3 (500k+)
  → ceil | 5,000
  → ceil(756200/5000) * 5000 = 760,000 ✅
```

## 🔄 Logic انتخاب رنج

```php
public static function getRoundingRange($price, $supplierId)
{
    return DB::table('supplier_price_rounding_ranges')
        ->where('supplier_id', $supplierId)
        ->where('is_active', true)
        ->where('min_price', '<=', $price)
        ->where(function($q) use ($price) {
            $q->whereNull('max_price')
              ->orWhere('max_price', '>', $price);
        })
        ->orderBy('priority', 'asc')
        ->first();
}
```
