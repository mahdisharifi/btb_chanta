# ⚡ خلاصه سریع نسخه 2.1 - تغییرات تیراژ مرجع

**نسخه:** 2.1.0  
**تاریخ:** 1404/06/07  
**زمان مطالعه:** 2 دقیقه

---

## 🎯 چه چیزی تغییر کرد؟

### 1️⃣ تیراژ مرجع جدید
**قبل:** تیراژ 0 (کارتن / خرده‌فروشی)  
**حالا:** تیراژ 2 (عمده‌فروشی کوچک) ← **پیش‌فرض جدید**

**چرا؟**
- رایج‌ترین سفارش در B2B
- قیمت‌گذاری واقعی‌تر
- مبنای مذاکرات تجاری

---

### 2️⃣ نمایش هوشمند
**قبل:**
```
تیراژ 0 → تیراژ 1 → تیراژ 2
```

**حالا:**
```
🏷️ تیراژ 1 (مرجع) → تیراژ 0 → تیراژ 2
```

**نتیجه:** تیراژ مهم اول نمایش داده می‌شود!

---

### 3️⃣ قفل قیمت نقدی

**وقتی "محاسبه خودکار" فعال است:**

| تیراژ | قیمت نقدی | قیمت نسیه |
|-------|-----------|-----------|
| تیراژ مرجع | ✅ قابل ویرایش | ✅ قابل ویرایش |
| سایر تیراژها | 🔒 قفل (محاسبه خودکار) | ✅ قابل ویرایش |

**مزیت:** حفظ تناسب قیمت‌ها + جلوگیری از خطا

## 📦 چه کسی تحت تأثیر قرار می‌گیرد؟

### ✅ تحت تأثیر قرار می‌گیرند:
- **محصولات جدید:** تیراژ مرجع پیش‌فرض = تیراژ 2
- **کاربران جدید:** با نمایش جدید آشنا می‌شوند

### ❌ تحت تأثیر قرار نمی‌گیرند:
- **محصولات موجود:** هیچ تغییری در قیمت‌ها ندارند
- **قیمت‌های ثبت شده:** بدون تغییر باقی می‌مانند
- **API:** بدون تغییر کار می‌کند

## 🎓 چطور استفاده کنم؟

### مثال عملی

1. **ورود به قیمت‌گذاری محصول**
2. **فعال کردن "محاسبه خودکار تیراژها"**
3. **تنظیم درصدها:**
   - تیراژ 0: `+10%` (گران‌تر)
   - تیراژ 1: `0%` (مرجع)
   - تیراژ 2: `-5%` (ارزان‌تر)
4. **وارد کردن قیمت نقدی فقط در تیراژ مرجع:**
   - مثال: `150,000` تومان
5. **ذخیره:**
   - تیراژ 0: `165,000` (خودکار)
   - تیراژ 1: `150,000` (دستی شما)
   - تیراژ 2: `142,500` (خودکار)

## 📊 مقایسه سریع

| ویژگی | قبل | حالا |
|-------|-----|------|
| تیراژ مرجع پیش‌فرض | تیراژ 0 | تیراژ 2 |
| ترتیب نمایش | ثابت (0→1→2) | هوشمند (مرجع اول) |
| قفل قیمت نقدی | ندارد | دارد |
| Badge مرجع | ندارد | دارد |
| قیمت نسیه | قابل ویرایش | قابل ویرایش (تغییری نکرده) |

## 💡 نکات طلایی

### ✅ انجام دهید:
- از تیراژ 2 به عنوان مرجع استفاده کنید (پیش‌فرض)
- قیمت نسیه را مجزا تنظیم کنید
- به Badge "تیراژ مرجع" توجه کنید

### ❌ انجام ندهید:
- سعی در ویرایش قیمت نقدی قفل‌شده
- نگرانی از داده‌های قبلی (تغییر نمی‌کنند)
- ترس از استفاده (سازگار با نسخه قبل است)

## 🆘 پشتیبانی

### سوالات متداول

**سوال:** آیا باید محصولات قدیمی را بروزرسانی کنم؟  
**جواب:** خیر! فقط محصولات جدید تحت تأثیر قرار می‌گیرند.

**سوال:** چرا نمی‌توانم قیمت نقدی تیراژ 0 را ویرایش کنم؟  
**جواب:** چون محاسبه خودکار فعال است. برای ویرایش دستی، آن را غیرفعال کنید.

**سوال:** قیمت نسیه چطور؟  
**جواب:** همیشه قابل ویرایش است، حتی در محاسبه خودکار.
