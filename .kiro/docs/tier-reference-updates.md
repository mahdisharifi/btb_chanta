## 📌 خلاصه تغییرات

### تغییرات اصلی:

1. **تیراژ 2 (عمده‌فروشی کوچک) به عنوان تیراژ مرجع** (قبلاً تیراژ 0 بود)
2. **ترتیب نمایش تیراژها**: تیراژ مرجع اول نمایش داده می‌شود
3. **قفل قیمت نقدی**: در حالت محاسبه خودکار، فقط قیمت نقدی تیراژ مرجع قابل ویرایش است
4. **قیمت نسیه**: همیشه قابل ویرایش می‌ماند (برای همه تیراژها)

## 🎯 دلایل تغییرات

### چرا تیراژ 2 (عمده‌فروشی کوچک) به عنوان مرجع؟

**منطق کسب‌وکار:**
- 📊 تیراژ 2 معمولاً **رایج‌ترین سفارش** است (1 تا 5 کارتن)
- 💰 قیمت‌گذاری **واقعی‌تر** نسبت به خرده‌فروشی
- 🎯 مبنای **مذاکرات تجاری** با خریداران
- ⚖️ **تعادل** بین قیمت خرده و عمده بزرگ

**مقایسه:**

| تیراژ | نوع | مناسب برای مرجع؟ | دلیل |
|-------|-----|------------------|------|
| تیراژ 0 | خرده‌فروشی | ❌ خیر | قیمت بالا، نامتداول |
| **تیراژ 1** | **عمده کوچک** | **✅ بله** | **رایج، واقعی، متعادل** |
| تیراژ 2 | عمده بزرگ | ❌ خیر | قیمت پایین، تخصصی |

## 🔧 تغییرات فنی

### 1. تغییر در `EditPrice.php`

**قبل:**
```php
public int $referenceTierIndex = 0; // کارتن (tier 0) به عنوان مرجع
```

**بعد:**
```php
public int $referenceTierIndex = 1; // تیراژ 2 (tier 1 / عمده‌فروشی کوچک) به عنوان مرجع
```

---

### 2. ترتیب نمایش تیراژها

**قبل:**
```
تیراژ 0 (خرده‌فروشی)
تیراژ 1 (عمده کوچک)
تیراژ 2 (عمده بزرگ)
```

**بعد (در حالت محاسبه خودکار):**
```
تیراژ 1 (عمده کوچک) ← 🏷️ تیراژ مرجع
تیراژ 0 (خرده‌فروشی)
تیراژ 2 (عمده بزرگ)
```

**کد:**
```php
@php
    // ✅ ترتیب نمایش تیراژها: تیراژ مرجع اول، سپس بقیه
    $sortedTiers = collect($quantityTiers);
    if ($autoCalculateTiers && $referenceTierIndex !== null) {
        $referenceTier = $sortedTiers->get($referenceTierIndex);
        $otherTiers = $sortedTiers->except($referenceTierIndex);
        $sortedTiers = collect([$referenceTierIndex => $referenceTier])->merge($otherTiers);
    }
@endphp
```

### 3. قفل قیمت نقدی

**قانون جدید:**
- ✅ **تیراژ مرجع**: قیمت نقدی قابل ویرایش
- 🔒 **سایر تیراژها**: قیمت نقدی قفل (محاسبه خودکار از تیراژ مرجع)
- ✅ **همه تیراژها**: قیمت نسیه (چک) قابل ویرایش

**کد Desktop:**
```php
@php
    // ✅ قیمت نقدی فقط برای تیراژ مرجع قابل ویرایش است (در حالت auto)
    $isCashDisabled = $autoCalculateTiers && $tierIndex !== $referenceTierIndex;
@endphp

<input type="number"
       wire:model.defer="priceMatrix.{{ $tierIndex }}.{{ $cashPriceType->id }}.price"
       @if($isCashDisabled) disabled readonly @endif
       class="... @if($isCashDisabled) opacity-60 cursor-not-allowed bg-gray-100 @endif">
       
@if($isCashDisabled)
    <div class="absolute inset-y-0 right-0 flex items-center pr-3 pointer-events-none">
        <x-heroicon-s-lock-closed class="w-4 h-4 text-gray-400"/>
    </div>
@endif
```

**کد Mobile:**
```php
@if($isCashDisabled)
    <span class="text-xs bg-amber-100 text-amber-700 px-2 py-0.5 rounded-full flex items-center gap-1">
        <x-heroicon-s-lock-closed class="w-3 h-3"/>
        قفل (محاسبه خودکار)
    </span>
@endif
```

## 📖 راهنمای کاربر

### سناریو 1: فعال‌سازی محاسبه خودکار

**مراحل:**

1. **فعال‌سازی:**
   - چک‌باکس "فعال‌سازی محاسبه خودکار تیراژها" را بزنید

2. **انتخاب تیراژ مرجع:**
   - پیش‌فرض: **تیراژ 2 (عمده‌فروشی کوچک)**
   - می‌توانید تغییر دهید

3. **تنظیم درصدها:**
   - تیراژ 0: +10% (گران‌تر از مرجع)
   - تیراژ 1: 0% (مرجع)
   - تیراژ 2: -5% (ارزان‌تر از مرجع)

4. **ویرایش قیمت:**
   - فقط **قیمت نقدی تیراژ مرجع** را وارد کنید
   - سایر تیراژها **خودکار محاسبه** می‌شوند
   - قیمت‌های **نسیه** (چک) همچنان قابل ویرایش هستند

---

### سناریو 2: غیرفعال کردن محاسبه خودکار

**اگر چک‌باکس را خاموش کنید:**
- ✅ همه قیمت‌ها (نقدی + نسیه) قابل ویرایش دستی می‌شوند
- ✅ ترتیب نمایش به حالت عادی برمی‌گردد (0 → 1 → 2)
- ✅ Badge "تیراژ مرجع" پنهان می‌شود

## 💡 نکات مهم

### برای توسعه‌دهندگان

1. **Property جدید در Livewire:**
   ```php
   public int $referenceTierIndex = 1; // پیش‌فرض: تیراژ 2
   ```

2. **Validation:**
   - قیمت نقدی تیراژ مرجع الزامی است
   - سایر تیراژها در حالت auto اختیاری هستند

3. **محاسبه خودکار:**
   - فقط وقتی `autoCalculateTiers = true` فعال می‌شود
   - قیمت نسیه همیشه مستقل است

---

### برای کاربران

1. **تیراژ مرجع چیست؟**
   - تیراژی که شما معمولاً بیشترین فروش را دارید
   - پیش‌فرض: عمده‌فروشی کوچک (1 تا 5 کارتن)

2. **چرا قیمت نقدی قفل است؟**
   - برای حفظ **تناسب قیمت‌ها**
   - تغییر یک قیمت، همه را بروزرسانی می‌کند
   - جلوگیری از **خطای انسانی**

3. **قیمت نسیه چطور؟**
   - همیشه قابل ویرایش
   - می‌توانید برای هر تیراژ مجزا تنظیم کنید
   - درصد کلی یا دستی
