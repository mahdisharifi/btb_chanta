# بهینه‌سازی SEO برای عمده‌فروشی B2B

## 📋 خلاصه

این مستند تغییرات اعمال شده در سیستم SEO را با تمرکز بر **عمده‌فروشی** شرح می‌دهد.

---

## 🎯 هدف

تمرکز SEO بر کلمات کلیدی **عمده‌فروشی** برای:
- افزایش رتبه در جستجوهای B2B
- جذب مشتریان خرده‌فروش و مشاغل
- تمایز از فروشگاه‌های خرده‌فروشی عادی

---

## 📊 جدول تغییرات پیش‌فرض SEO

### 1. صفحه محصول (`buildSeoData`)

| فیلد | قبل از تغییر | بعد از تغییر (عمده‌فروشی) |
|------|-------------|--------------------------|
| **Title** | `{product} \| {category} \| {site}` | `خرید عمده {product} \| {category} \| {site}` |
| **Description** | `{short_description} \| قیمت: {price}` | `{short_description} \| قیمت عمده از {price} \| فروش عمده` |
| **Keywords** | `{title},{category},خرید عمده,قیمت عمده` | `{title} عمده,خرید عمده {title},{category} عمده,قیمت عمده {title},فروش کارتنی,فروش عمده` |
| **OG Title** | `{seo_title}` | `خرید عمده {product}` |

**Fallback Description (اگر short_description خالی باشد):**
```
"خرید عمده {product} با بهترین قیمت از عمده‌فروشی چن تا؟. فروش عمده به صورت کارتن و پالت | قیمت عمده از {price} تومان"
```

---

### 2. صفحه لیست محصولات (`buildIndexSeo`)

| حالت | Title | Description |
|------|-------|-------------|
| **پیش‌فرض** | `فروش عمده محصولات \| {site}` | `خرید عمده محصولات با بهترین قیمت از عمده‌فروشی چن تا؟` |
| **جستجو** | `خرید عمده {query} \| {site}` | `قیمت عمده {query} — مقایسه قیمت‌های عمده‌فروشی` |
| **دسته‌بندی** | `خرید عمده {category} \| {site}` | `قیمت عمده {category} — مشاهده و خرید عمده محصولات` |

**Keywords پیش‌فرض:**
```
خرید عمده, قیمت عمده, فروش عمده, عمده‌فروشی
```

---

### 3. صفحه دسته‌بندی (`buildCategorySeo`)

| فیلد | پیش‌فرض (اگر خالی) |
|------|-------------------|
| **Title** | `خرید عمده {category} \| {site}` |
| **Description** | `قیمت عمده {category} — خرید عمده و فروش کارتنی محصولات {category}` |
| **Keywords** | `{category} عمده,خرید عمده {category},قیمت عمده {category},فروش کارتنی` |

## 🔧 تغییرات Schema.org

### اضافه شدن فیلدهای B2B:

```json
{
  "@type": "Product",
  "productID": "SKU-123",
  "offers": {
    "@type": "AggregateOffer",
    "businessFunction": "http://purl.org/goodrelations/v1#Sell",
    "eligibleQuantity": {
      "@type": "QuantitativeValue",
      "minValue": 1,
      "unitText": "کارتن"
    }
  },
  "audience": {
    "@type": "BusinessAudience",
    "audienceType": "خرده‌فروشان و مشاغل"
  }
}
```

**توضیح:**
- `businessFunction`: نوع عملیات (فروش عمده)
- `eligibleQuantity`: حداقل سفارش (کارتنی)
- `audience`: مخاطب (مشاغل B2B)

## 🎯 مزایای SEO عمده‌فروشی

### 1. **هدفمندی بهتر**
- جستجوگران با کلمه "عمده" قصد خرید عمده دارند
- افزایش نرخ تبدیل (Conversion Rate)

### 2. **کاهش رقابت**
- کلمات کلیدی عمده‌فروشی رقابت کمتری دارند
- رتبه‌گیری سریع‌تر در Google

### 3. **Rich Snippets بهتر**
- Schema.org با فیلدهای B2B
- نمایش "حداقل سفارش" در Google

### 4. **تمایز از خرده‌فروشی**
- کاربران می‌فهمند شما عمده‌فروش هستید
- جلوگیری از سردرگمی
