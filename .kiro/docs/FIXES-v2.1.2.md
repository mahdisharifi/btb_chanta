# 🔧 اصلاحات نسخه 2.1.2

**تاریخ:** 1404/06/07  
**نوع:** Bug Fixes & UX Improvements

---

## 🐛 مشکلات برطرف شده

### 1️⃣ **تیراژ مرجع به کارتن (تیراژ 0) برگشت** ✅

**مشکل قبلی:**
- تیراژ مرجع = تیراژ 2 (عمده‌فروشی کوچک)
- قیمت نقدی کارتن قفل بود!

**حل شده:**
- تیراژ مرجع = تیراژ 0 (کارتن / تیراژ 1)
- قیمت نقدی کارتن **قابل ویرایش** است
- سایر تیراژها از کارتن محاسبه می‌شوند

---

### 2️⃣ **حذف قابلیت انتخاب تیراژ مرجع** ✅

**قبل:**
```
┌────────────────────────────────┐
│ انتخاب تیراژ مرجع:             │
│ [▼ تیراژ 1 / تیراژ 2 / ...]   │
└────────────────────────────────┘
```

**بعد:**
```
┌────────────────────────────────┐
│ ✅ تیراژ مرجع: کارتن (تیراژ 1) │
│ (ثابت - قابل تغییر نیست)       │
└────────────────────────────────┘
```

**دلیل:** کارتن همیشه باید پایه محاسبات باشد

---

### 3️⃣ **ترتیب نمایش تیراژها به حالت عادی برگشت** ✅

**قبل:**
```
تیراژ 1 (مرجع) ← اول
تیراژ 0
تیراژ 2
```

**بعد:**
```
تیراژ 0 (کارتن / مرجع) ← اول
تیراژ 1 (عمده کوچک)
تیراژ 2 (عمده بزرگ)
```

---

### 4️⃣ **حذف Badge "تیراژ مرجع"** ✅

**دلیل:** دیگر نیازی نیست، چون کارتن همیشه اول است

---

### 5️⃣ **توضیحات بروزرسانی شد** ✅

```
💡 چگونه کار می‌کند؟
• تیراژ مرجع: کارتن (تیراژ 1) - پایه محاسبات
• برای سایر تیراژها درصد افزایش یا کاهش تعیین کنید
• با تغییر قیمت نقدی کارتن، سایر تیراژها خودکار محاسبه می‌شوند
• قیمت نقدی سایر تیراژها قفل می‌شود
• قیمت‌های نسیه همیشه قابل ویرایش هستند
• می‌توانید محاسبه خودکار را غیرفعال کنید و قیمت‌ها را دستی وارد کنید
```
