# راهنمای جامع محصول، فروش و شعبه

تاریخ مبنا: ۱۴۰۵/۰۸/۲۱، برابر با ۲۰۲۶/۱۱/۱۲. این مجموعه رفتار نسخهٔ فعلی کد را توضیح می‌دهد و برای تحلیل کسب‌وکار، توسعه، پشتیبانی و استخراج تست نوشته شده است. این مستند فقط فهرست تغییرات نیست؛ هر فصل ماهیت داده، چرخهٔ عمر، مجوزها، ورودی و خروجی، وابستگی، اثر جانبی و معیار پذیرش بخش مربوط را پوشش می‌دهد.

## قرارداد خواندن

- **رفتار موجود**: نتیجه‌ای که از کد فعلی استخراج شده است؛ تأیید اجرای تمام سناریوها نیست.
- **قاعدهٔ کسب‌وکار**: نتیجهٔ مورد انتظار محصول. اگر کد با آن تفاوت دارد، شناسهٔ `GAP` معرفی شده است.
- **پیشنهاد**: مسیر توسعهٔ آینده؛ نباید تست موفق فعلی برای آن فرض شود.
- **حذف پیشنهاد فروش**: حذف ارتباط فروش شعبه و قیمت‌های وابسته؛ محصول مرجع باقی می‌ماند.
- **حذف شعبه**: حذف رکورد شعبه پس از تعیین تکلیف قیمت‌ها؛ محصول مرجع و نسخهٔ محصول شعبه حذف نمی‌شوند.
- **تأیید محصول** و **فعال‌بودن فروش** دو تصمیم مستقل‌اند. قبول انتقال نیز هیچ‌یک از این دو تأیید را جایگزین نمی‌کند.

## مرجع و محدودهٔ اطمینان

منابع اصلی در انتهای هر فصل آمده‌اند. پیاده‌سازی Laravel/Livewire، مدل‌ها، سرویس‌ها، Blade، مهاجرت‌ها و آزمون‌های موجود مبنای سند هستند. مسیرها نسبت به ریشهٔ مخزن نوشته شده‌اند. تنظیمات نقش‌ها، محتوای پایگاه داده، پیکربندی صف و فایل و قالب کاتالوگ می‌توانند نتیجهٔ محیط اجرایی را تغییر دهند؛ تست باید آن‌ها را صریح تنظیم کند.

این مجموعه شامل فرم محصول مدیر و تأمین‌کننده، تیراژها، شعبه، پیشنهاد فروش، قیمت، انتقال و مصرف‌کننده‌های مستقیم این داده‌هاست. گزارش مالی، پرداخت، سفارش و انبار مستقل صرفاً با حذف یک محصول یا شعبه قابل استنتاج نیستند؛ هر وابستگی تاریخی باید پیش از توسعهٔ حذف در همان زیرسامانه بررسی شود. هیچ دستور حذف دادهٔ محیط واقعی برای تهیهٔ این مستند اجرا نمی‌شود.
