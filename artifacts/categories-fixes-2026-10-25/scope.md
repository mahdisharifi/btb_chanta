# دامنهٔ اصلاحات دسته‌بندی

مسیرها: /categories، /categories/{slug}، مدیریت ایجاد/ویرایش دسته، sitemap دسته‌ها و کارت مشترک محصول.

نقش‌های درگیر: مهمان و نقش‌های دارای تنظیم مجوز قیمت، مدیر دسته، مصرف‌کنندگان کارت محصول.

داده‌ها: درخت فعال دسته‌ها، شمارش محصولات منتشرشده، تاریخ اعتبار قیمت، وضعیت تأمین‌کننده، نامک‌های قبلی و تصویر دسته.

بخش‌های مستقل پیاده‌سازی: catalog_fix (درخت، Laravel، query، cache و کنترلر)، admin_fix (Livewire، اعتبارسنجی، فایل و نامک)، price_fix (قیمت و مجوزهای کارت)، root (طراحی، جستجو، موبایل، دسترس‌پذیری و قالب سئو). این‌ها نقش‌های پیاده‌سازی هستند؛ بازبینی مستقل نهایی جدا ثبت خواهد شد.

خارج از این اصلاح: تغییر قرارداد شمارش API و حذف ایندکس‌های تکراری که پیشنهادهای مستقل گزارش بازبینی بودند؛ عملیات پرداخت و صف تغییر نمی‌کنند.

فایل‌های از پیش موجود نامرتبط (آرشیو RAR و فایل storage/framework/lsp) حفظ می‌شوند.
