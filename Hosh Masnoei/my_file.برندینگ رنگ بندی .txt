دستورالعمل سیستم طراحی و یکپارچگی بصری (Brand Identity Guidelines)
پروژه باید با زبان طراحی «مدرن، لوکس و تجاری» و با تکیه بر پالت اختصاصی پروژه ساخته شود. تمام کامپوننت‌ها باید از این قواعد پیروی کنند:

۱. پالت رنگی اختصاصی (Brand Palette):

رنگ اصلی (Brand Primary): فقط از gold-400 (#d4af37) برای المان‌های کلیدی (دکمه‌های اصلی، آیکون‌های مهم، حالت‌های Active/Focus) استفاده شود.
تغییرات رنگی (States): برای Hover از gold-500 و برای رنگ‌های پس‌زمینه ملایم (مانند Badge یا Highlight) از gold-50 یا gold-100 استفاده شود.
رنگ‌های خنثی (Neutral): برای متن‌ها، حاشیه‌ها و پس‌زمینه‌ها از ترکیب zinc (به‌عنوان مکمل استاندارد) یا خاکستری‌های استاندارد Tailwind استفاده شود.
ممنوعیت: استفاده از هرگونه رنگ برند غیر از پالت gold در بخش‌های اصلی اکشن (CTA) ممنوع است.
۲. تایپوگرافی:

فونت اصلی در تمامی بخش‌ها Vazir است.
وزن‌بندی فونت باید خوانایی بالا را تضمین کند (تیترها font-bold یا font-semibold و متن‌های معمولی font-normal).
۳. استایل کامپوننت‌های پایه (Component Styling):

دکمه‌های اصلی (Primary Buttons): استفاده از bg-gold-400 hover:bg-gold-500 text-white rounded-xl.
دکمه‌های ثانویه (Secondary Buttons): استفاده از حاشیه خاکستری سبک (border border-zinc-200) و متن تیره (text-zinc-700).
کارت‌ها و سکشن‌ها (Cards): پس‌زمینه سفید خالص، حاشیه ظریف (border-zinc-200) و rounded-2xl برای گوشه‌ها. استفاده از shadow-sm برای جدا کردن کارت از پس‌زمینه.
اینپوت‌ها و فرم‌ها: استفاده از border-zinc-300 برای حالت عادی و focus:border-gold-400 focus:ring-gold-400 برای حالت تعاملی.
حالت حذف (Danger): استفاده از قرمز ملایم و کلاس‌های bg-red-50 text-red-600 border border-red-200.
۴. قواعد رسپانسیو و UI/UX:

موبایل‌فرست (Mobile-First): در دستگاه‌های کوچک (موبایل)، استفاده از ساختار «کارت» (Card-based UI) بجای جدول‌های گسترده الزامی است.
اهداف لمسی: حداقل ارتفاع برای دکمه‌ها و المان‌های تعاملی در موبایل ۴۸ پیکسل (h-12) باشد.
فضاسازی (Spacing): استفاده از گپ‌های منظم (gap-4 یا gap-6) برای حفظ نظم بصری.
۵. الزامات فنی:

عدم استفاده از فونت‌های خارجی (CDN)؛ فقط استفاده از فایل‌های لوکال Vazir.
تمام آیکون‌ها باید از پکیج blade-heroicons استفاده کنند.
در تمامی صفحات، رنگ‌بندی و سایز فونت‌ها باید طبق این قرارداد رعایت شود تا کاربر حس یکپارچگی کامل را داشته باشد.
